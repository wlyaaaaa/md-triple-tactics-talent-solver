# 游戏王大师决斗「三战之才」活动决策仿真与视频生成自动化流水线
> 本项目基于真实的《游戏王：大师决斗》（Yu-Gi-Oh! Master Duel）卡池数据与 1 亿次多进程蒙特卡洛（Monte Carlo）仿真，按科乐美官方活动结算规则，求解「三战之才（Triple Tactics Talent）」活动的最优交卡博弈策略（最大化钻石收益）。同时包含一套完整的视频自动化生成流水线，能够自动将策略结论、幻灯片、配音、背景音乐和字幕渲染合成出 4K 画质的视频。

---

## 🌟 项目亮点

1. **真实卡池驱动**：自动调用 YGOPRODeck 开放 API 获取最新的 Master Duel 活跃怪兽数据，剔除禁限卡，获取最真实的特征分布。
2. **多进程蒙特卡洛模拟**：通过 1 亿次随机抽样模拟，精确计算各种策略下的收益均值、95% / 99% 概率下的保底钻石收益。
3. **收益对冲博弈**：依据鸽巢原理与协方差对冲机制，首创“暗光地高频属性双押”分配策略，将属性保底失效率从 25% 降低至 2.33%。
4. **全自动视频渲染与装配**：包含从 Markdown 报告渲染、PDF 导出、自定义 PPTX 样式幻灯片绘图、封面生成，到视频合成（音轨对齐、BGM 混音、SRT 字幕压制）的一键式视频创作流水线。

## ⚙️ 核心技术流水线 (`06_代码/`)

项目通过编号 1 到 9 的脚本构成一个完整的流水线，你可以按顺序运行：

1. **[1_取数清洗.py](file:///e:/Pictures/三战之才/06_代码/1_取数清洗.py)**
   - 接口请求 YGOPRODeck 获取 MD 最新卡池，清洗掉非怪兽卡及被禁用的怪兽，输出 `md_monsters_active.csv`。
2. **[2_特征剪枝.py](file:///e:/Pictures/三战之才/06_代码/2_特征剪枝.py)**
   - 统计卡池的属性、种族、攻击力频数分布。提取排名前 9 的高频种族与攻击力，并过滤掉空节点与只含大奖热门卡的拥挤节点（防止均分钻石被稀释）。
3. **[3_模板搜索.py](file:///e:/Pictures/三战之才/06_代码/3_模板搜索.py)**
   - 自动搜索最优的 9 特征分配方案（3天 × 3插槽），确保种族和攻击力不重复，并在此处应用属性的对冲划分。
4. **[4_纠错仿真_取最高.py](file:///e:/Pictures/三战之才/06_代码/4_纠错仿真_取最高.py)**
   - 基于科乐美官方“只取当日单场最高一项”的结算规则，利用 Python `multiprocessing` 多进程跑 1 亿次蒙特卡洛模拟，并输出准确的收益期望与分位数保底。
5. **[5_生成策略报告.py](file:///e:/Pictures/三战之才/06_代码/5_生成策略报告.py)**
   - 根据搜索到的特征分布，自动生成包含 9 个卡位对应的“冷门远古凡骨怪兽”的策略报告，避免大众交卡导致大奖钻石被瓜分稀释。
6. **[6_渲染PDF整页.py](file:///e:/Pictures/三战之才/06_代码/6_渲染PDF整页.py)**
   - 使用 PyMuPDF (`fitz`) 将生成的 PDF 策略报告页面转换为高清 PNG 图片，作为片尾“相关文档”的展示素材。
7. **[7_生成幻灯片.py](file:///e:/Pictures/三战之才/06_代码/7_生成幻灯片.py)**
   - 使用 `PIL` 绘图模块自动绘制高品质的幻灯片单页 PNG 帧，免去了手动制作 PPT 的繁琐步骤。
8. **[8_生成封面.py](file:///e:/Pictures/三战之才/06_代码/8_生成封面.py)**
   - 自动排版并生成用于视频发布的高清封面图。
9. **[9_装配视频.py](file:///e:/Pictures/三战之才/06_代码/9_装配视频.py)**
   - 核心合成器。读取配音音频、背景音乐、幻灯片图片以及 SRT 字幕，一键拼装导出 4K 高画质视频。
10. **[工具_Markdown转PDF.py](file:///e:/Pictures/三战之才/06_代码/工具_Markdown转PDF.py)**
    - 辅助工具。将项目文档 Markdown 转化为排版美观的高清 PDF，底层使用 Windows 自带的 Edge 浏览器无头打印。

## 🛠️ 快速开始

### 1. 环境准备
- **操作系统**：推荐使用 Windows（PDF 渲染与字体排版脚本依赖 Microsoft Edge/Chrome 内核）。
- **Python 版本**：Python 3.8 或以上。
- **外部依赖**：确保系统中安装了 `FFmpeg`，且其可执行文件路径已加入到系统环境变量 `PATH` 中（视频合成脚本 `9_装配视频.py` 需要用到）。

### 2. 安装依赖
在项目根目录下，运行以下命令安装 Python 库依赖：
```bash
pip install -r requirements.txt
```

### 3. 一键运行流水线
按照顺序依次执行 `06_代码/` 下的各个脚本：
```powershell
# 切换到代码目录下
cd 06_代码

# 执行数据拉取与清洗
python 1_取数清洗.py

# 执行特征剪枝与建模
python 2_特征剪枝.py

# 模板生成与最优策略搜索
python 3_模板搜索.py

# 进行多进程蒙特卡洛仿真评估（1亿次模拟约需要几分钟）
python 4_纠错仿真_取最高.py

# 后续的报告与视频素材渲染
python 5_生成策略报告.py
python 6_渲染PDF整页.py
python 7_生成幻灯片.py
python 8_生成封面.py

# 组装视频（需在 09_BGM与素材/ 下放入对应的音频素材，输出 4K 成片）
python 9_装配视频.py
```

## 📊 核心研究结论摘要

在游戏王大师决斗的「三战之才」活动中，科乐美官方的结算是**「单场每天只取最高一项，不予叠加；三天中取最高分的一天作为该场得分」**。

基于 1 亿次 Monte Carlo 仿真得到的结论：
- **传统的散投方案**（每一天都散投不同属性）：收益期望 ≈ 285 钻。
- **2.0 高频对冲方案**（在占比高达 71.4% 的暗、光、地三大属性上，每天各押两个槽位）：**期望钻石收益提升至 ≈ 376 钻**，且拥有 95% 置信度下 ≥ 210 钻、99% 置信度下 ≥ 200 钻的强力保底。

### 推荐的 9天 循环押注模式：
| 循环天 | 属性押注 | 特征 1 (卡片 1) | 特征 2 (卡片 2) | 特征 3 (卡片 3) |
| :--- | :--- | :--- | :--- | :--- |
| **第 1 / 4 / 7 天** | 暗、暗、水 | 暗 / 龙族 / 2500 | 暗 / 恶魔族 / 0 | 水 / 魔法师族 / 1500 |
| **第 2 / 5 / 8 天** | 光、光、风 | 光 / 天使族 / 1600 | 光 / 机械族 / 1000 | 风 / 鸟兽族 / 1200 |
| **第 3 / 6 / 9 天** | 地、地、炎 | 地 / 战士族 / 1800 | 地 / 兽族 / 800 | 炎 / 炎族 / 1700 |

*关于推荐卡位的冷门“幽灵凡骨卡”列表，请参考 `03_策略报告/` 目录下的详细文档。*
